# E-commerce Data Processing with Pandas

This project demonstrates how to process and combine e-commerce datasets using **Python and Pandas**.

## Files

* `Day9_Orders.csv` – Order information
* `Day9_Customers.csv` – Customer information
* `Day9_Products.csv` – Product information
* `Day9_Processed_Ecommerce_Dataset.csv` – Final processed dataset
* `Day9_Processed_Ecommerce_Dataset.ipynb` – Jupyter Notebook

## Concepts Used

* Pandas DataFrames
* `merge()`
* `concat()`
* `apply()`
* DateTime operations
* Data transformation
* CSV file export

## Output

The three datasets are combined into a clean and meaningful e-commerce dataset containing customer, product, order, sales, and date-related information.
